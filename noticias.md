# Noticias

## Nueva página web

Como podéis ver, ahora tenemos un nueva **página web** con mejores sistemas de autenticación y mejores recursos para empleados y usuarios.<br>
Estamos intentando revolucionar nuestro sistema, ya que el anterior se ha quedado ineficiente para la nueva base.

Nos hemos quedado con un sistema mucho más complicado pero más personalizable, ya que mientras que antes se usaba _google sites_, conocido por ser un editor básico, ahora se programa diréctamente, algo más complicado, pero con mejores resultados.

Esperamos que os guste esta nueva web y que se haga simple y fácil de entender.
